# Roni Domi Portfolio Demo v2

A minimalist portfolio concept inspired by the existing terminal portfolio, but intentionally much simpler.

Design choices:
- Off-white background
- Extremely faint grid lines retained from the original
- Small monospace technical labels
- Large editorial typography
- Blue is reserved for optional future accents
- No CRT effects, scanlines, or gimmicky interactions
- Projects and actual work are the focus

Replace the placeholder Resume, GitHub, and LinkedIn links with the real URLs.
